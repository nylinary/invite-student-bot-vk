# Беседы вузов: что создать руками

VK перестал давать сообществу создавать беседы (ошибка 9 «Flood control» — после
шести подряд блок держится часами). Поэтому оставшиеся беседы заводятся с личного
аккаунта, а бот их подхватывает.

## Что делать с каждой беседой

1. Создать беседу с названием из таблицы, например **«ИТМО | НОЧЬ СТУДЕНТА»**.
2. Добавить сообщество: страница сообщества → **Добавить в беседу** → выбрать её.
3. Назначить сообщество **администратором** беседы (создателю беседы VK это разрешает):
   информация о беседе → Участники → пролистать вниз до сообществ → ⋯ → Назначить администратором.
4. Отправить в беседе команду из таблицы, например `/bind itmo`.

Дальше бот сам: поставит общую аву, опубликует и **закрепит** описание, напишет
объяснение для студентов с кнопкой на себя, привяжет беседу к вузу и положит
ссылку-приглашение в карточку вуза.

Если аву и закреп поставить не удалось, бот прямо в ответе на `/bind` скажет
«проверь, что я администратор» — значит шаг 3 не сработал.

Проверить всё разом: `/admin` → **🔍 Проверить привязки**.

## Если VK снова начнёт пускать

Очередь бота выключена, чтобы не плодить дубли. Включить обратно:
`/admin` → «🎓 Список вузов» → «🏗 Создать беседы». Он заведёт беседы только тем вузам,
у которых их ещё нет.
